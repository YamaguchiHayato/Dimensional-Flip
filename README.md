- 開発期間: 08/20〜11/30
- 自作コードの中心: `GameTemplate/Game/Src`
- ゲーム用アセット: `GameTemplate/Game/Assets`

このリポジトリには、ゲーム本体のコード、ゲーム用アセット、ベースとして使用しているテンプレート・エンジン関連ファイルが含まれています。作品確認時は、まず `PORTFOLIO.md` で概要と制作範囲を確認してください。
